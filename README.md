# ⚡ Foysal Tools - Advanced Cyber Admin Panel ⚡

**Foysal Tools** হলো একটি অত্যাধুনিক, হাই-টেক সাইবার অ্যাডমিন প্যানেল যা বিশেষভাবে **Termux** এবং **HopWeb** এর মাধ্যমে অ্যান্ড্রয়েড ও পিসিতে সহজেই হোস্ট ও পরিচালনা করার জন্য তৈরি করা হয়েছে।

---

## 🌟 প্রধান সুবিধাসমূহ (Key Features)

1. **অত্যাধুনিক সাইবার ডিজাইন (Futuristic Cyberpunk UI)**:
   - গ্লাস-মরফিজম (Glassmorphism), মেগা নিয়ন গ্লো এফেক্ট ও ম্যাট্রিক্স ডিজিটাল রেইন ব্যাকগ্রাউন্ড।
   - ৬টি স্পেশাল কালার থিম (Neon Cyan, Matrix Green, Cyber Violet, Crimson Red, Amber Gold, Deep Ocean)।
   - মোবাইল ও ডেস্কটপ উভয়ের জন্যই ১০০% রেসপন্সিভ (অ্যান্ড্রয়েডের জন্য কাস্টম মোবাইল বটম বার সহ)।

2. **ডাইনামিক কাস্টম টুলস স্টুডিও (Custom Tool Studio / Maker)**:
   - **টুলস ক্রিয়েটর**: আপনার ইচ্ছামতো যেকোনো নতুন টুল তৈরি করে প্যানেলে যুক্ত করতে পারবেন।
   - **Webview / Iframe টুল**: যেকোনো ওয়েবসাইট বা অনলাইন টুলকে সরাসরি প্যানেলের ভেতর লাইভ পপআপে রান করতে পারবেন।
   - **কাস্টম HTML / JS স্ক্রিপ্ট রানার**: আপনার নিজের কোডিং করা যেকোনো HTML/JS টুল সরাসরি স্যান্ডবক্স মোডে রান হবে।
   - **Termux কমান্ড টুল**: টার্মিনাল কমান্ড এবং স্ক্রিপ্ট শর্টকাট তৈরি করে ১-ক্লিকে কপি ও এক্সিকিউট করতে পারবেন।
   - এডিট, ডিলিট, পিন (Dashboard Favorites) ও ক্যাটাগরাইজেশন করার সম্পূর্ণ কন্ট্রোল।

3. **ইন-বিল্ট অ্যাডভান্সড সাইবার টুলস (Pre-installed Tools)**:
   - **Cyber Hash Generator & Matcher**: রিয়েল-টাইম MD5, SHA-1, SHA-256, SHA-512 হ্যাশ তৈরি ও টার্গেট হ্যাশ ভেরিফিকেশন।
   - **Multi-Encoder & Decoder**: Base64, Hexadecimal, Binary, URL, HTML Entities এবং ROT13 সাইফার।
   - **Military-Grade Key & Pass Generator**: আল্ট্রা-সিকিউর পাসওয়ার্ড, ২৫৬-বিট API কি এবং UUIDv4 জেনারেটর।
   - **Live IP & Geolocation Intelligence**: পাবলিক আইপি, ISP, ASN, দেশ, শহর, অক্ষাংশ-দ্রাঘিমাংশ এবং গুগল ম্যাপ লোকেশন।
   - **Cloudflare DoH DNS Resolver**: রিয়েল-টাইম ডোমেন রেকর্ডস (A, AAAA, MX, TXT, CNAME, NS) কোয়েরি।
   - **JSON Beautifier & Validator**: ফরম্যাট, মিনিফাই এবং স্ট্রাকচার ডিবাগিং।
   - **Regex Pattern Tester**: রেগুলার এক্সপ্রেশন লাইভ টেস্ট ও ম্যাচিং গ্রুপস হাইলাইটার।
   - **Text Transformer**: Uppercase, Lowercase, Title, camelCase, snake_case, kebab-case, ও ক্যারেক্টার কাউন্টার।
   - **High-Tech QR Code Maker**: যেকোনো টেক্সট বা লিংকের জন্য সাইবার কিউআর কোড জেনারেশন ও ডাউনলোড।

4. **Termux Supercharger Hub**:
   - টার্মাক্স প্যাকেজ আপডেট, স্টোরেজ পারমিশন, পাইথন/নোড/পিএইচপি সেটআপ এবং Cloudflare টানেল সহ প্রয়োজনীয় সব কমান্ড ১-ক্লিকে কপি ও এক্সিকিউটের সুবিধা।

5. **সম্পূর্ণ কাস্টমাইজেশন ও নিরাপত্তা (Full Control & Customization)**:
   - প্যানেলের নাম, লোগো, অ্যাডমিন নাম ও সাবটাইটেল নিজের মতো পরিবর্তন করার সুবিধা।
   - অ্যাডমিন পিন (PIN Protection) সিকিউরিটি লক।
   - কাস্টম সিএসএস (CSS Studio) লাইভ ইনজেক্টর।
   - সম্পূর্ণ ব্যাকআপ ডাউনলোড (Export JSON) এবং রিস্টোর (Import JSON) সুবিধা।

## 🚀 কিভাবে ব্যবহার ও হোস্ট করবেন? (How to Run & Host)

### পদ্ধতি ১: HopWeb অ্যাপের মাধ্যমে (Recommended for HopWeb)
1. **HopWeb** অ্যাপটি ওপেন করুন।
2. `Open Project` বা `Folder` অপশন থেকে `foysal-tools` ফোল্ডারটি সিলেক্ট করুন।
   - পাথ: `/data/data/com.termux/files/home/foysal-tools` (অথবা আপনার ফোন স্টোরেজে কপি করা ফোল্ডার)
3. HopWeb এর ভেতরে থাকা **Run / Play** বাটনে চাপ দিন।
4. ব্যস! **Foysal Tools** আপনার HopWeb ইন্টারনাল ব্রাউজার অথবা ফোনের ক্রোমে লাইভ ওপেন হয়ে যাবে।

---

### পদ্ধতি ২: Termux এর মাধ্যমে (Termux One-Click Server)
Termux টার্মিনালে নিচের কমান্ডটি রান করুন:

```bash
cd ~/foysal-tools
./server.sh
```

এটি স্বয়ংক্রিয়ভাবে লোকাল ওয়েব সার্ভার চালু করবে এবং আপনাকে লোকাল লিঙ্ক দিয়ে দিবে:
```
👉 Localhost:   http://localhost:8080
👉 Localhost:   http://127.0.0.1:8080
```
যেকোনো ব্রাউজারে লিংকটি ওপেন করলেই অ্যাডমিন প্যানেল ওপেন হবে।

সার্ভার বন্ধ করতে `Ctrl + C` চাপুন।

## 🛠️ নিজের ইচ্ছামতো টুলস তৈরি করার নিয়ম:
1. প্যানেলে লগইন করে **Tool Studio** ট্যাবে যান।
2. **"Create New Tool"** বাটনে ক্লিক করুন।
3. টুলের নাম দিন, ক্যাটাগরি এবং আইকন সিলেক্ট করুন।
4. Tool Type সিলেক্ট করুন:
   - **Webview / Modal Iframe**: যেকোনো সাইটের URL দিন।
   - **HTML / JS Script**: আপনার কাস্টম কোড পেস্ট করুন।
   - **Termux Command**: আপনার প্রিয় টার্মিনাল কমান্ড দিন।
5. **Save Tool** চাপলেই টুলটি ইনস্ট্যান্ট আপনার প্যানেলে যোগ হয়ে যাবে!
